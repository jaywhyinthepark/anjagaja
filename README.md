# 앉아가자

서울 버스의 월간 시간대별 승하차 흐름을 자동 분석하는 Streamlit 웹앱이다.

## 실행

Python 3.10 이상에서 이 폴더를 열고 다음을 실행한다.

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

노선번호와 오전 07:00~09:00 또는 오후 18:00~20:00를 선택한다. 그래프·승차 집중 표시·분석 결과 다운로드가 자동 갱신된다.

## 포함 자료

첨부 원본 1,507,675,275바이트를 전체 검토해 최신 월인 2026년 9월만 추출했다. 원본은 2015년 1월~2026년 9월, 141개월, 5,600,957행이다. 배포 자료는 667개 노선, 42,155행이다. 원본 한글 설명 헤더와 영문 헤더 중 영문 헤더를 사용한다. ID는 문자열로 보존한다. 원본은 수정하지 않았다.

## 분석 기준

- 오전은 07시·08시, 오후는 18시·19시 인원을 합산한다.
- 순승차 = 승차 합계 − 하차 합계. 모든 값은 해당 월 누적 인원이다.
- 같은 노선·정류장 ID를 합산한다. 같은 ID의 이름 변형은 함께 표시한다.
- 승차 집중: 노선 전체 정류장 순승차의 80백분위 이상이면서 양수인 정류장. 동점이면 모두 포함한다. 탐색용 규칙이다.
- 운행 순서가 없을 때 그래프는 순승차 내림차순이며, 앞선 정류장 추천은 제공하지 않는다.

## 방향별 운행 순서 연결

`stop_order_template.csv`의 열 구조로 해당 월·노선의 방향별 전체 정류장을 확인해 입력한 후 앱에서 올린다. 빈 템플릿은 실제 순서를 담고 있지 않다. `seq`는 원본 행 순번이며 운행 순서로 사용하지 않는다.

| 열 | 내용 |
|---|---|
| route_no | 노선번호 |
| use_ym | 통계와 같은 기준 월, 예: 202609 |
| direction | 확인한 운행 방향 |
| stop_sequence | 방향별 기점부터 1, 2, 3… 전체 연속 순서 |
| std_bus_sttn_id | 원본과 연결하는 표준 정류장 ID |
| source_url | 순서를 확인한 출처 URL |

등록 후 방향을 선택하면 운행 순서로 그래프를 표시하고, 승차 집중 정류장의 앞선 1~2개 정류장을 후보로 표시한다. 순서 누락·중복·매칭 실패는 차단한다. 반복 경유 정류장은 통과 차수별 통계가 없어 추천을 차단한다. 파일 내용과 기준 월의 정확성은 등록자가 출처와 대조해야 한다.

실제 운행 순서 자료는 아직 포함하지 않았으므로 기본 상태의 이전 정류장 추천은 미완성이다.

## 자동화 범위와 한계

사용자의 선택에 따라 집계·탐지·시각화하는 **분석 자동화 웹앱**이다. 월별 데이터 자동 수집, 정기 실행, 알림은 포함하지 않는다. 최신 자료 갱신은 `bus_latest.csv` 교체가 필요하다.

현재 빈 좌석이나 착석 확률은 계산하지 않는다. 월 전체 요일이 섞여 있고 차량별 운행 횟수·정원·재차 인원이 없다. 방향 순서를 연결해도 원본 통계가 방향별로 분리되지 않는 정류장은 방향별 수요를 구분할 수 없다. 순승차 누적합을 실제 차내 인원으로 표시하지 않는다. 앞선 정류장은 보행 경로와 착석을 보장하지 않는다.

## 검증

최신 월 모든 노선의 두 시간대 집계를 원본 열 합계와 대조한다. 운행 순서 연결과 누락 차단은 합성 입력으로 검증한다. 현재 작업 환경에는 Streamlit이 없어 실제 서버 실행 및 화면 검증은 수행하지 못했다.
